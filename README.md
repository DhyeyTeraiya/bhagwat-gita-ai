# Bhagwat Gita Project

A web-based application to read and explore the sacred text of Bhagwat Gita.

## Features

- Clean and modern user interface
- Chapter-wise navigation
- Sanskrit verses with translations
- Responsive design for all devices

## Project Structure

```
bhagwat-gita/
├── index.html
├── styles/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Navigate through chapters using the chapter buttons
