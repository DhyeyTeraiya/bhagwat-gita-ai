# 🕉️ Bhagwat Gita AI Guidance System

A web app for reading the **Bhagwat Gita** chapter by chapter — Sanskrit verses
with translations — plus an **AI guidance** mode that answers questions about
the text using **Google Gemini**.

## Features

- Chapter-wise navigation through the Gita
- Sanskrit verses with translations, cleanly rendered
- Responsive layout for mobile and desktop
- **AI guidance** — ask a question and get a contextual answer generated by Gemini
- Sanskrit text normalisation on the server (IAST → Devanagari mapping,
  duplicate-verse cleanup)

## Stack

| Layer | Technology |
| :--- | :--- |
| Front-end | HTML, CSS, vanilla JavaScript (`index.html`, `js/`, `styles/`) |
| Back-end | Node.js + Express (`cors`, `body-parser`) |
| AI | `@google/generative-ai` — `gemini-pro` model |
| Config | `dotenv` |

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Create a `.env` file in the project root:

   ```env
   GOOGLE_API_KEY=your_google_ai_studio_key
   PORT=3000
   ```

3. Start the server:

   ```bash
   npm start          # node server.js
   # during development:
   npm run dev        # nodemon
   ```

4. Open **http://localhost:3000**.

Get an API key from [Google AI Studio](https://aistudio.google.com/app/apikey).

## Notes

- **`.env` is committed to this repository.** If it ever contained a real key,
  rotate it in Google AI Studio, then add `.env` to `.gitignore` and remove it
  from tracking: `git rm --cached .env`.
- `node_modules/` is also tracked, which makes clones large — remove it from
  tracking with `git rm -r --cached node_modules` and add it to `.gitignore`.
